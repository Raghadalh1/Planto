Planto 🌱
A plant care reminder application built using SwiftUI.

 Features
- Add plant reminders
- Edit and delete reminders
- Manage watering schedules
- Local notifications

 Architecture
The application follows the MVVM architecture:

- Models: Manage application data.
- Views: Display the user interface.
- ViewModels: Handle application logic and state management.

 Technologies
- Swift
- SwiftUI
- Xcode
